# Joint Stain-Aware Fusion and Quantile-Free Uncertainty Quantification for Efficient Cervical Cell Detection

This repository contains the official PyTorch implementation of our paper:

> **Joint Stain-Aware Fusion and Quantile-Free Uncertainty Quantification for Efficient Cervical Cell Detection**
